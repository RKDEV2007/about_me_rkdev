# RKDEV Portfolio

Личный сайт-портфолио frontend-разработчика. Проект рассказывает о подходе к работе, показывает подборку сайтов и React-приложений, а также дает быстрые контакты для обсуждения задач.

## Что внутри

- Главная страница с профессиональным позиционированием.
- Каталог проектов с карточками, тегами, ссылками на демо и GitHub.
- Модальное окно с подробностями проекта.
- Контактный блок с Telegram и GitHub.
- Темный адаптивный редизайн: глубокая мятная основа, `#B9E5C8` для светлых акцентов и `#2B1A12` как дополнительный контраст.

## Технологии

- React
- Vite
- CSS split by structure: base, layout, home, projects, contact, modal, responsive

## Запуск

```bash
cd about_me_react
npm install
npm run dev
```

## Проверка сборки

```bash
npm run lint
npm run build
```
